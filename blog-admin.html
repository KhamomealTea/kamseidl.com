Publishing a post

  1. Write the post here. Your work is saved in this browser automatically, so you can close the tab.
  2. Click Download posts.js.
  3. Replace content/posts.js in your site folder with the file you just downloaded.
  4. Re-upload the site folder to your host. The post is live.

Cover images: drop the image file into an images/ folder next to the site and use images/your-file.jpg as the URL.
